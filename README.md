# Mãos à Obra

Site institucional da Mãos à Obra — reparos, reformas e manutenção em Saquarema/RJ.

## Publicação

A Netlify deve usar a pasta `out` como diretório de publicação. Essa configuração já está definida em `netlify.toml`.

## Desenvolvimento

Os arquivos editáveis ficam na raiz deste repositório. Após uma alteração, mantenha a versão publicada em `out` sincronizada antes de enviar o commit.
